手工试拍流程：装样并记录编号 → 固定角度 → 设置一种照明并等待实物稳定 →
点击该视图采集 → 检查原图 → 分别完成另一照明及其余角度。当前软件不会
自动切换灯，也没有独立材料存在/照明参考输入的实物确认。样本界面“完成”只
表示十二视图归档齐全，不表示表面覆盖率、缺陷检出率或照明方案已被验证。

重启恢复建议使用独立验收样本：先采两至三个视图，导出并记下 session_id，
停止服务再重新启动，恢复同一会话，核对图像和历史，再补齐剩余视图。配置
改变时创建新会话；历史归档保持原样。禁止用验证删除操作清理既有用户样本。
